Song settings

Instrument The main (first) instrument of the player, will also be saved in the song you record
Pitch The pitch of the player, will also be saved in the song you record
Tempo (BPM) Beats per minute, used by the metronome and will be used when converting the song with the composer
Reverb (cave mode) Makes it sound like you are in a cave

Player settings

Metronome beats After how many times a stronger beat is played
Metronome volume The volume of the metronome
Note name type The type of text which will be written on the note
Keyboard size Scales the keyboard size
Keyboard vertical position The vertical position of the keyboard
Note animation Toggle the animation of the notes (will reduce performance)

Practice settings

Show visual sheet Show the sheet above the keyboard (might reduce performance)
Approach Rate (AR) The time between when the notes appear and when they reach the end (in ms)
Number of rows in visual sheet The number of rows in the visual sheet, more rows might cause lag
Number of columns in visual sheet The number of columns in the visual sheet, more columns might cause lag
Loop song selection in practice mode When you reach the end of the selected notes in the song in practice mode, it will loop back to the start
Hide notes in practice mode During the practice mode, hide the notes so you can test your memory, the visual sheet will still be visible
Storage is not persisted The browser didn't allow to store data persistently, it might happen that you will lose data when cache is automatically cleared. To get persistent storage, add the app to the home screen. If that still doesn't work, make sure you do a backup often

Player shortcuts

Space
Toggle keyboard recording
ShiftLeft+KeyS
Stop playing / recording / practicing
ShiftLeft+KeyR
Restart the song or practice
ShiftLeft+KeyM
Toggle the menu
Escape
Close the menu

Composer shortcuts

Space
Toggle play / pause
KeyA
Select the previous column (Holdable)
KeyD
Select the next column (Holdable)
KeyQ
Remove the selected column (Holdable)
KeyE
Add a column after the selected column (Holdable)
ArrowUp
Select the previous layer (Holdable)
ArrowDown
Select the next layer (Holdable)
ArrowRight
Move to the next breakpoint (Holdable)
ArrowLeft
Move to the previous breakpoint (Holdable)
KeyK
Raise or lower the keyboard in the pro view
ControlLeft+KeyZ
Undo the last change made to the song (Holdable)
ControlLeft+KeyY
Redo the change that was just undone (Holdable)
Shift + Wheel
Scroll the pro view vertically
Ctrl/⌘ + Wheel
Zoom the pro view rows (a trackpad pinch works too)
